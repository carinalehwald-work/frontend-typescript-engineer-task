# Digital Service

Eine barrierefreie und responsive Web-Komponente auf Basis nativer Web-Technologien.

## Ziel

Dieses Projekt entstand im Rahmen einer Frontend-Entwicklungsaufgabe.

Die zentrale Komponente stellt mindestens drei unterschiedliche Inhaltstypen bereit und passt ihre Navigation an die jeweilige Bildschirmgröße an:

* **Desktop (≥ 800px):** Tab-Navigation
* **Mobile (< 800px):** Accordion

Die Entwicklung erfolgt nach dem **Mobile-First-Prinzip** mit Fokus auf Wiederverwendbarkeit, Accessibility und einer sauberen technischen Umsetzung.

## Technologien

* HTML5
* CSS3
* TypeScript
* Web Components
* Native Web APIs
* Vitest

## Anforderungen

* keine Frameworks
* keine UI-Libraries
* responsive
* Mobile First
* barrierefrei
* mindestens drei Inhaltstypen
* wiederverwendbare Komponentenstruktur
* automatisierte Tests
